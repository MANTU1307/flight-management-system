# ✈️ Flight Management System

A backend application built using Spring Boot that allows users to manage flights, bookings, and payments.

## 🚀 Features
- User Registration & Login (JWT Authentication)
- Flight Management (CRUD APIs)
- Booking System
- Payment Integration (Razorpay)

## 🛠 Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Razorpay API

## 🔐 Security
- Environment variables used for sensitive data
- No hardcoded secrets
- .gitignore configured for secure files
